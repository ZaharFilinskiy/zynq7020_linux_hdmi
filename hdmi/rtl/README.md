# Интерфейс видеоблока: автономная PL-ветка

axis_hdmi_source (TEST_PATTERN=1) генерирует кадр 1280×720 без PS/DDR/VDMA. Его выход M_AXIS подключён к S_AXIS блока axis_hdmi_video; оба модуля находятся в Block Design.

- Пиксель: TDATA[31:0]=0x00RRGGBB.
- TUSER: начало кадра; TLAST: последний пиксель строки.
- Передача: TVALID && TREADY; при остановке приёмника пиксель и метки удерживаются.
- PixelClk: около 74.166667 МГц, SerialClk: около 370.833333 МГц.
- Развёртка: 1280/110/40/220 по горизонтали, 720/5/5/20 по вертикали; положительные HS/VS.
- Генератор: 8 полос, нижние шахматные клетки 32×32, рамка 2 пикселя.

Внешние S_AXIS-входы генератора в этой ветке привязаны к нулю и не используются. axis_hdmi_video сохраняет протокол поиска SOF, контроля EOL и диагностический stream_error для возможности дальнейшего расширения.

Проект main с PS/VDMA/Linux находится в другой ветке. Подробнее об этой автономной схеме: ../../HDMI_PL_ONLY_RU.md.
