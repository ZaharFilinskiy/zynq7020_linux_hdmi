# Интерфейс видеоблока

`axis_hdmi_video` добавлен как Module Reference в `design_1.bd`.
Вход: AXI4-Stream Video, 32 бита на пиксель, `0x00RRGGBB`,
`TUSER=SOF`, `TLAST=конец строки`, поддерживается `TREADY`.
Часы входа — 25,2 МГц. AXIS Clock Converter пересекает границу
100/25,2 МГц; все интерфейсы VDMA работают на 100 МГц.

Режим: 640×480, горизонтальные интервалы 640/16/96/48,
вертикальные 480/10/2/33, HSync/VSync отрицательные.
Полный кадр 800×525, ровно 60 Гц при 25,2 МГц.
Передатчик получает отдельно 126 МГц для сериализации 10:1 DDR.

Если данных нет или нарушены SOF/EOL, остаток кадра чёрный,
синхронизация монитора продолжает работать. Блок пропускает повреждённый
поток до следующего SOF и удерживает его до начала экранного кадра.
`stream_error` — флаг для будущего ILA, сбрасывается `resetn`.
При запуске до инициализации VDMA он ожидаемо устанавливается.

Для камеры нужны буферизация и согласование формата/частоты:
камера, которая не умеет останавливаться по TREADY, не должна
подключаться напрямую. Следующий этап — S2MM в DDR и два/три буфера.
Текущий simplefb использует один фиксированный буфер: возможен tearing.
